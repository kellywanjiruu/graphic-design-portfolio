How to Add Your Designs

To add your own designs to this portfolio:

  1. Create an images folder in the same directory as this HTML file
  2. Add your design images to the images folder
  3. Copy a gallery item above and paste it in the gallery-grid section
  4. Update the following attributes:
<div class="gallery-item" 
     data-category="posters" <!-- Change to posters, logos, branding, or social -->
     data-image="images/your-image.jpg" <!-- Your filename -->
     data-title="Your Design Title"
     data-description="Brief description here"
     data-tools="canva,photoshop,illustrator,corel"> <!-- Comma separated -->
    <div class="item-preview"></div>
    <div class="item-info">
        <h3>Your Design Title</h3>
        <p>Brief description here</p>
        <div class="item-tags">
            <span class="tag" style="background-color: #6A0DAD;">Canva</span>
            <span class="tag" style="background-color: #FF1493;">Photoshop</span>
        </div>
    </div>
</div>

Tip: Choose tag colors from our color palette: #6A0DAD, #9D00FF, #00CED1, #FF1493, #FF8C00, #20B2AA
